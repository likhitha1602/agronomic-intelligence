# 🌾 Agronomic Intelligence
### Deep Learning–Based Crop Pest Detection and Decision Support System

## 📌 Overview
Agronomic Intelligence is an end-to-end **computer vision–based deep learning system** that automatically identifies crop pests from images and provides **pesticide recommendations**.  
The system supports farmers and agronomists by enabling early pest detection, reducing crop loss, and promoting **Integrated Pest Management (IPM)** practices.

---

## 🎯 Objectives
- Automate crop pest identification using deep learning
- Achieve high accuracy with low-latency inference
- Provide pest-specific pesticide recommendations
- Support data-driven agricultural decision-making

---

## 🧠 Key Features
- 📷 Image-based pest detection using deep learning  
- 🧪 Multi-class classification across **9 pest categories**  
- ⚡ Real-time inference with optimized performance  
- 🌱 Decision support aligned with IPM standards  
- 📊 Achieved **96.8% classification accuracy**

---

## 🛠️ Tech Stack
- **Programming Language:** Python  
- **Deep Learning Frameworks:** TensorFlow, Keras  
- **Model Architecture:** MobileNet  
- **Backend:** Flask  
- **Mobile Application:** React Native  
- **Libraries & Tools:** NumPy, OpenCV, Matplotlib
